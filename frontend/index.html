QUORUM

Four specialised agents collaborate to solve competitive programming problems through structured planning, implementation, sandboxed verification, and critical review. Benchmarked head-to-head against a single-agent baseline under identical conditions.

Launch Console →
THE AGENTS
PLANNER qwen-turbo

Decomposes the problem into a structured plan: approach, edge cases, complexity target, and test ideas. On a replan, incorporates the Critic's feedback to correct a wrong strategy.

Output: {"approach", "edge_cases", "test_ideas", "complexity_target"}
CODER qwen-max

Implements the plan. Returns code only — no prose. Up to 4 attempts per problem. Each retry receives a structured failure report from the Verifier, not raw tracebacks.

Output: ```python\n# complete stdin→stdout program\n```
VERIFIER deterministic

Runs the Coder's solution against sample and hidden tests inside an isolated sandbox (Alibaba Cloud Function Compute). Summarises failures into compact structured reports to save tokens downstream.

Output: {"passed", "failures": [{test_id, expected, actual}]}
CRITIC qwen-plus

Reviews failures and makes a three-way decision. This is the disagreement-resolution mechanism Track 3 requires — the Critic can override the current approach entirely.

Output: {"action": "patch" | "replan" | "give_up", reasoning, guidance}
